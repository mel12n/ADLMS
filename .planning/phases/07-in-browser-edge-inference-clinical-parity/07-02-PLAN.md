  <name>Task 1: Implement edge_detector.js with ORT-Web 1.18.0 hygiene, SIMD probe, and unified payload</name>
  <files>mvp_web/inference/edge_detector.js</files>
  <action>
    Create `mvp_web/inference/edge_detector.js` as a UMD/IIFE module (`window.ADLMS_EDGE_DETECTOR` + `module.exports`).
    Implement:
    - `supportsWasmSimd()`: `WebAssembly.validate` on the minimal 128-bit SIMD byte sequence (returns boolean, catches errors).
    - `resolveModelVariant(meta, searchStr)`: reads `?model=<variant_id>` from query string, validates strictly by exact `id` match in `meta.variants[]` (preventing path traversal per 07-RESEARCH.md Security Domain), and defaults to `yolo11n_seg_416_fp32`.
    - `configureOrtEnv(ortRef, searchStr)`: sets `ort.env.wasm.wasmPaths = './vendor/ort/'`, `ort.env.wasm.numThreads = 1`, `ort.env.wasm.proxy = false`, and `ort.env.wasm.simd = (params.get('simd') === '0') ? false : supportsWasmSimd()`.
    - Singleton session cache (`_sessionCache`) keyed by `variant.id`: creates `ort.InferenceSession.create('./models/' + variant.filename, { executionProviders: ['wasm'], enableCpuMemArena: false, enableMemPattern: false, graphOptimizationLevel: 'all' })` once and reuses it across consecutive plates.
    - `preprocessImageToNchw(img, imgsz)`: draws `img` onto a reusable offscreen `<canvas>` of `imgsz x imgsz` filled with `#727272` (`rgb(114, 114, 114)`) using `computeLetterbox(img.naturalWidth, img.naturalHeight, imgsz)` and converts RGBA to NCHW `Float32Array` (`[1, 3, imgsz, imgsz]`, normalized `/ 255.0`).
    - `runEdgeInference(img, opts)`:
      1. Loads `model_meta.json` (cached), resolves variant, ensures singleton session.
      2. Measures `preprocess_ms`, `inference_ms`, `postprocess_ms`, `total_ms` with `performance.now()`.
      3. Creates `new ort.Tensor('float32', nchw, [1, 3, imgsz, imgsz])`, runs `session.run({ [inputName]: inputTensor })`, copies `output0.data` and `output1.data` into plain `Float32Array`s, and calls `inputTensor.dispose()` + `output.dispose()` for every output tensor inside a `finally` block.
      4. Calls `ADLMS_YOLO_DECODE.decodeYoloSeg(...)` and `ADLMS_SOBEL_CV.extractBlurredLuminance(...)` + `validateZoneGeometry(...)` on the original image RGBA to enrich each detection with `sobel_mm`, `delta_r_mm`, `geo_valid`, `geo_alert`, `geo_message`.
      5. Returns the exact `/api/analyze` JSON contract (`scale_px_per_mm`, `scale_mm_per_px`, `median_disk_px`, `disk_count`, `zone_count`, `inference_ms`, `preprocess_ms`, `postprocess_ms`, `total_ms`, `runtime_mode: 'edge-wasm'`, `simd_enabled`, `model_variant: variant.id`, `detections[]`).
  </action>

  <name>Task 2: Implement inference_router.js for automatic Edge WASM vs Local API routing</name>
  <files>mvp_web/inference/inference_router.js</files>
  <action>
    Create `mvp_web/inference/inference_router.js` as a UMD/IIFE module (`window.ADLMS_INFERENCE_ROUTER` + `module.exports`).
    Implement:
    - `detectRuntimeMode(env)`:
      1. If `hostname === 'appassets.androidplatform.net'` → return `'edge-wasm'`.
      2. Parse `search` query param `mode`: if `'edge-wasm'` → return `'edge-wasm'`; if `'local-api'` → return `'local-api'`.
      3. Otherwise probe `GET /api/health` using `fetch` with an `AbortController` (`600 ms` timeout): if `res.ok` and `(await res.json()).model_exists === true`, return `'local-api'`.
      4. On timeout, network error, or non-ok response → return `'edge-wasm'`.
    - `analyzePlate(file, img, opts)`:
      1. Resolves active mode (cached or via `detectRuntimeMode`).
      2. If `'local-api'`, executes `POST /api/analyze` with `{ image_base64, organism, group, standard, enable_ocr: true, ocr_angles: 8 }`; if the POST fails due to network unavailability, falls back cleanly to `'edge-wasm'` and updates active mode.
      3. If `'edge-wasm'`, invokes `window.ADLMS_EDGE_DETECTOR.runEdgeInference(img, opts)`.
      4. Returns the unified JSON payload with `runtime_mode` set to `'local-api'` or `'edge-wasm'`.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string (`?model=`, `?mode=`, `?simd=`) → `edge_detector.js` & `inference_router.js` | Untrusted query parameters select model file path and execution mode |
| Client browser → Local Python API (`/api/health`, `/api/analyze`) | Localhost HTTP boundary with 600 ms timeout and automatic offline fallback |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-03 | Tampering | `edge_detector.js :: resolveModelVariant` | high | mitigate | Strict allow-list lookup against `model_meta.json` `variants[].id`; reject any unknown or path-traversal string (`../`) and fall back to `yolo11n_seg_416_fp32` |
| T-07-04 | Information Disclosure | `inference_router.js :: detectRuntimeMode` | medium | mitigate | When running on `appassets.androidplatform.net` (APK), never issue `/api/health` or any network request; route immediately to `edge-wasm` |
| T-07-SC | Tampering | Vendored runtime | high | mitigate | Static `./vendor/ort/` path pinned in `configureOrtEnv`; no dynamic CDN script loading |
</threat_model>
