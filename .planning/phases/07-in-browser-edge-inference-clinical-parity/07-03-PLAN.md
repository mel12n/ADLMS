  <action>
    Create `scripts/verify_js_parity.py` (runnable with `.\venv\Scripts\python.exe scripts/verify_js_parity.py`) that:
    1. Loads `mvp_web/models/yolo11n_seg_416_fp32.onnx` with Python `onnxruntime.InferenceSession`.
    2. Selects the held-out `1:1` validation plates from `data/Antibiogram_demo/val.txt` (plus 1 synthesized `1600x1200` `4:3` plate created by letterboxing/padding a held-out plate into `1600x1200` so `padTop > 0` is genuinely exercised).
    3. For each plate:
       - Runs Python `letterbox_image` + `onnxruntime` inference to obtain exact `output0 [1, 39, 3549]` and `output1 [1, 32, 104, 104]`.
       - Runs Python reference decoding (`verify_onnx_parity.py` / `measure_zones.py` 6.0 mm median scale + 1:1 pairing) and Python `cross_validation.py` 36-ray Sobel on the plate.
       - Writes `output0.bin`, `output1.bin`, and plate `rgba.bin` to a temporary directory and invokes `node` to execute `mvp_web/inference/yolo_seg_decode.js` + `mvp_web/inference/sobel_cv.js` on those exact binary buffers.
       - Pairs Python vs JS detections by nearest centroid and computes per-plate and aggregate zone-diameter MAE (`|diam_js - diam_py|`) and Sobel `delta_r_mm` difference.
    4. Writes `exports/js_parity_report.json` with per-plate results (`1:1` and `4:3`), overall MAE, and `pass: mae < 0.20`.
    5. Exits with status `0` if `overall_mae < 0.20` and `4:3` plate MAE `< 0.20`, else exits non-zero with a clear diagnostic summary.
