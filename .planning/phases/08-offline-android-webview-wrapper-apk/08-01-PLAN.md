<task type="tracer">
  <name>Task 1: Create Windows Android toolchain bootstrap and edge asset syncer</name>
  <files>scripts/setup_android_toolchain.ps1, scripts/sync_edge_assets.py</files>
  <action>
Create `scripts/setup_android_toolchain.ps1` (idempotent PowerShell script):
- Check if `java -version` (JDK 17) is available or `%LOCALAPPDATA%\Android\jdk-17` exists; if missing, download Eclipse Temurin JDK 17 Windows x64 zip and extract to `%LOCALAPPDATA%\Android\jdk-17`, setting `JAVA_HOME` for the session.
- Check `%LOCALAPPDATA%\Android\Sdk` (reusing existing `platform-tools\adb.exe` — NEVER overwrite `platform-tools\`).
- If `cmdline-tools\latest\bin\sdkmanager.bat` is missing, download Android `commandlinetools-win-11076708_latest.zip` and extract to `%LOCALAPPDATA%\Android\Sdk\cmdline-tools\latest`.
- Accept licenses (`yes | sdkmanager --licenses`) and install `platforms;android-34` and `build-tools;34.0.0` if missing.
- Print clear status of `JAVA_HOME`, `ANDROID_HOME`, and `adb.exe` path.

Create `scripts/sync_edge_assets.py` (Python 3 CLI):
- Source: `mvp_web/` at repo root; Destination: `android/app/src/main/assets/mvp_web/`.
- Default mode: copy `mvp_web/` (excluding `models/*.onnx` except `yolo11n_seg_416_fp32.onnx`, plus `models/model_meta.json`, and excluding desktop-only preview images `*.jpg` in root `mvp_web/` if not needed).
- Support `--all-models` flag to include all 4 Phase 6 ONNX variants from `mvp_web/models/` or `exports/`.
- Support `--dry-run` flag to print planned file copies and total size without writing.
- Clean destination before syncing so stale files are removed.
  </action>
  <verify>
    <automated>python scripts/sync_edge_assets.py --dry-run</automated>
  </verify>
  <done>`scripts/setup_android_toolchain.ps1` exists and `python scripts/sync_edge_assets.py --dry-run` exits 0 listing `mvp_web/` + `yolo11n_seg_416_fp32.onnx` + `model_meta.json`.</done>
