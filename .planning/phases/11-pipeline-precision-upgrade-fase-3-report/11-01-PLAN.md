1. `detectPlateRoi(rgba, width, height, opts)`: downscale luminance (`0.299*R + 0.587*G + 0.114*B`) to `dw <= 160` px, apply 1-pass separable 3x3 box blur, compute `|Gx| + |Gy|` gradient magnitude and 85th-percentile threshold, estimate center `(cx, cy)`, cast 72 outward rays (every 5 deg) from `0.25 * min(dw, dh)` to `0.52 * max(dw, dh)` to locate outermost dish rim peaks, reject outliers with median + `2.5 * MAD`, and fit rotated ellipse `(majorAxis, minorAxis, angleRad)` via 2x2 covariance eigenvalues. Compute `fillRatio = (2 * majorAxis) / min(dw, dh)`. If fewer than 18 valid rim rays are found, return `found: false, cropped: false, tiltDeg: 0, tiltWarning: false, perspectiveCompensated: false, cropBox: { x: 0, y: 0, w: width, h: height }`. If `fillRatio > 0.85` (D-01), set `cropped: false` and return full-frame `cropBox`. Otherwise compute `axisRatio = clamp(minorAxis / majorAxis, 0.5, 1.0)`, `tiltDeg = Math.acos(axisRatio) * 180 / Math.PI`, `tiltWarning = tiltDeg > 5.0` (D-07), `perspectiveCompensated = tiltDeg > 2.0 && axisRatio >= 0.75`, and a clamped square `cropBox` around `(cx, cy)` with `4%` margin. All coordinates clamped strictly to `[0, width]` / `[0, height]` (ASVS V5).
2. `extractRoiCanvas(imgOrCanvas, roiInfo, opts)`: if `!roiInfo || (!roiInfo.cropped && !roiInfo.perspectiveCompensated)`, return `{ canvas: imgOrCanvas, width, height, roiInfo }` with zero copy. Otherwise draw onto an offscreen canvas capped at `maxEdge <= 1024`; when `roiInfo.perspectiveCompensated` is true and canvas 2D context supports `translate`/`rotate`/`scale`, apply `-angleRad` rotation, scale minor axis by `majorAxis / minorAxis`, and rotate back by `+angleRad` before cropping to `cropBox`.
3. `applyTileClaheLuminance(rgba, width, height, opts)`: 8x8 tile CLAHE (`tilesX = 8`, `tilesY = 8`, `clipLimit = 2.0`) returning a single `Float32Array(width * height)` in `[0, 255]` with bilinear interpolation across the 4 nearest tile CDFs (D-03).
4. `applyTileClaheRgba(rgba, width, height, opts)`: scales RGB proportionally from `applyTileClaheLuminance()` and returns `Uint8ClampedArray(width * height * 4)` for visual CLAHE rendering. Keep total module clean, well-structured, and zero-dependency.</action>
